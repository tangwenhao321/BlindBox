## 1. 产品概述

本项目为 **魔力赏 / 盲盒** 类电商应用（品牌名在 App 内为「盲盒星球」），核心能力包括：

- 用户购买盲盒，支付后按概率抽取盒内赏品（商品）
- 赏品进入 **虚拟仓库**，可 **发货**、**兑换余额**、**分解碎片**、**挂牌集市出售**
- **优惠券**、**连拍优惠**、**运费模板**（发货时计费，开盒下单默认不收运费）
- **推广邀请**：邀请码绑定、团队、佣金、里程碑福利
- **福利**：签到、新人任务、幸运币等
- **社区晒单**、**欧皇榜**、**公平性验证**
- **VIP 会员**（管理端配置，App 会员权益入口）
- 管理端：盲盒/商品/库存/活动/订单/发货/退款/审核等运营能力

**三端组成**：

| 端 | 技术 | 使用者 |
|----|------|--------|
| 手机 App | React Native + Expo | C 端用户 |
| 管理后台 | Vue3 + Vite + Element Plus | 运营/管理员 |
| 服务端 | Spring Boot 3 + Jimmer + Sa-Token | 支撑前后台 |

## 5. 启动项目（完整步骤）

### 5.1 首次环境准备

```powershell
# 1. 进入主目录
cd d:\A-WorkSpace\blindBox\mystery-box-main

# 2. 启动 MySQL + Redis
docker compose -f docker-compose.local.yml up -d

# 3. 后端：配置 application-private.yml / DEV_DB_PASSWORD
cd mystery-box-backend
mvn -DskipTests compile

# 4. 管理端依赖
cd ..\mystery-box-admin
npm install
npm run api-admin    # 需后端已启动，同步 TS 类型

# 5. App 依赖
cd ..\mystery-box-mobile-app
npm install
copy .env.example .env   # 编辑 API 地址
```

### 5.2 日常启动（推荐顺序）

**方式 A：Windows 一键脚本**

```powershell
cd d:\A-WorkSpace\blindBox\mystery-box-main
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1
```

**方式 B：手动分终端**

**终端 1 — 后端**

```powershell
cd d:\A-WorkSpace\blindBox\mystery-box-main\mystery-box-backend
$env:REDIS_URL="redis://127.0.0.1:6380/0"
$env:DEV_DB_PASSWORD="CHANGE_ME"
mvn -DskipTests spring-boot:run "-Dspring-boot.run.profiles=dev,private"
```

等待日志出现：`Tomcat started on port 9912`。

验证：

```powershell
curl http://127.0.0.1:9912/actuator/health
# 期望 status: UP
```

**终端 2 — 管理端**

```powershell
cd d:\A-WorkSpace\blindBox\mystery-box-main\mystery-box-admin
npm run dev
```

浏览器打开：`http://localhost:5177`

**终端 3 — 手机 App（Metro）**

```powershell
cd d:\A-WorkSpace\blindBox\mystery-box-main\mystery-box-mobile-app
npm run start
```

Metro 地址：`http://localhost:8083`

### 5.3 真机调试检查清单

- [ ] 手机与电脑同一 WiFi  
- [ ] `.env` 中 API 为电脑局域网 IP  
- [ ] Windows 防火墙放行 **9912**、**8083**

### 7.4 用户操作 SOP：注册与登录

1. 打开 App → 未登录时进入登录页  
2. **登录**：手机号 + 密码 → 登录  
3. **注册**：切换注册 → 填手机号、密码、验证码（dev 填 `000000`）→ 可选邀请码 → 注册  
4. **忘记密码**：验证码 + 新密码  
5. 登录成功后进入首页 Tab  

API：`POST /front/user/login`、`/register`、`PUT /password`

### 7.5 用户操作 SOP：浏览与开盒

1. **首页/商城** 浏览盲盒列表，可按分类、排序筛选  
2. 点击盲盒进入 **盲盒详情**  
3. 查看：赏品图、池子余量、概率、战报、保底进度等  
4. 选择 **抽数**（连拍优惠见价格说明）  
5. 选择开盒模式（若该盒支持）：  
   - **即时开赏**：直接排队下单  
   - **排队模式**：先排队，轮到后弹出确认订单  
   - **选盒（柜面）**：选择格口后下单  
   - **全收模式**：锁定剩余池子后下单  
6. 点击底部 **开盒/下单** → **确认订单** 弹窗  
7. 核对：商品、数量、优惠、合计（开盒 **不含运费**）  
8. 勾选用户协议 → **立即支付**  
9. 完成支付（mock 环境在模拟支付窗确认）  
10. 进入 **开奖动画** → 结果页可查看赏品、再支付（若待支付）、去仓库  

API 摘要：

- 创建订单：`POST /front/mystery-box-order/create`（Header `x-draw-mode`: `instant` | `queue` | `buyout`）  
- 报价：`POST /front/mystery-box-order/calculate`  
- 支付：`POST .../pay/mock` 或 `.../prepay/wechat` 等  

### 7.6 用户操作 SOP：我的订单

入口：**我的 → 我的订单**

| Tab | 含义 | 数据来源说明 |
|-----|------|----------------|
| 全部 | 仓库中当前赏品 + 待付款订单 | 仓库 API + 订单 API |
| 发货申请 | 已提交、待发货的赏品行 | 仓库 `pendingShipRequest` |
| 待收货 | 已发货待确认收货的订单 | 订单状态筛选 |
| 已完成 | 已完成订单 | 订单状态筛选 |
| 待支付 | 未支付订单 | 订单状态筛选 |

操作：

- 点击订单/赏品行 → **订单详情**  
- 待支付：可 **继续支付** 或 **取消订单**  
- 待收货：可 **确认收货**  
- 下拉刷新同步最新状态  

### 7.7 用户操作 SOP：仓库（赏品处置）

入口：**仓库 Tab**

| 操作 | 步骤 | API |
|------|------|-----|
| 查看赏品 | 商品/盒子 Tab 切换列表 | `GET /front/warehouse/items` |
| 批量发货 | 勾选赏品 → 批量发货 → 选地址 → 报价运费 → 提交 | `POST /front/warehouse/ship/quote` → `ship/submit` |
| 兑换余额 | 选择赏品 → 兑换余额（确认预估金额） | `POST .../redeem-balance` |
| 分解碎片 | 选择赏品 → 分解（确认碎片预估） | `POST /front/fragment/decompose` |
| 挂牌出售 | 设置价格 → 上架到集市 | `POST /front/marketplace/listings` |
| 发货申请记录 | 仓库内入口或 `ship-requests` 页 | `GET /front/warehouse/ship/requests` |

> **说明**：开盒时 **不要求** 收货地址；**首次发货** 时选择地址并支付运费。

### 7.8 用户操作 SOP：赏品集市

1. 进入 **赏品集市**  
2. Tab：**集市**（浏览购买）/ **我的挂牌** / **已购入**

## 14. 常见问题排障

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| App 首页一直加载 | API 地址不可达 | 检查 `.env` 局域网 IP、防火墙、后端 health |
| 登录失败 | 后端未启/数据库未初始化 | 启后端、检查 `database.sql`、测试账号 |
| 支付无反应 | 引导遮罩/网络/订单创建失败 | 关闭引导；看 Metro 日志；查后端错误 |
| 确认订单关不掉 | 多层 Modal 叠加 | 更新到最新 App；点上方空白或 × |
| 订单「全部」与「发货申请」数量不一致 | 数据源不一致（旧版） | 使用统一仓库 API 的版本 |
| 排队不动 | Redis 未启 | 启 Redis，核对 `REDIS_URL` |
| 管理端菜单缺页 | Flyway 未跑 | 启后端自动迁移或查 `flyway_schema_history` |
| Flyway checksum 失败 | 迁移文件被改 | 按 README 执行 repair |
| Maestro 失败 | 设备未连/账号错误 | 检查 `MAESTRO_TEST_PHONE` 等 |

更多移动端排障：`MOBILE_APP_SETUP.md`  
运维 on-call：`docs/OPS_RUNBOOK.md`
